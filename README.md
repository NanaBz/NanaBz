### ⚡ Featured Project

**[League Scheduler](https://github.com/NanaBz/League-Scheduler)** · [Live](https://league-scheduler-bqav.vercel.app/)

League Scheduler started on the pitch — playing in Academic City's football league and getting frustrated with repetitive, conflicting fixtures. I looked at how professional leagues solve scheduling, found the **Circle Method**, and adapted it with randomized starting positions so reschedules did not always lock the same team in place.

What began as a scheduling fix grew into a broader school football ecosystem — league management, cup competitions, and a custom fantasy football layer built on live match data.
